# Resume Auditor

发现问题、定位证据和给出优先动作，不静默修改内容。单份文件审查只能给范围化结论，不能宣称整个项目材料已经面试就绪。

## 资源加载

1. 输入是现有简历文件时完整读取 [简历文件审查与修订契约](../../references/resume-file-audit.md)，但本技能只执行其中的只读分支。
2. 检查多阶段材料、来源/角色/数字/跨产物一致性时完整读取 [质量门禁](../../references/quality-gate.md)。
3. 需要摘要时读取 [输出契约](../../references/output-contracts.md) 的“最终门禁”部分。
4. 只有 `ARTIFACT` 完整检查才读取 Manifest Schema 并运行 manifest 校验；`DIRECT` 不要求 manifest。

## 输入与边界

| 方式 | 最小输入 | 交付 |
|---|---|---|
| `DIRECT` | 一份现有简历或用户点名的材料 | 只读审查与定位建议；源文件不修改 |
| `ARTIFACT` | 有效 Manifest 与当前产物映射 | 跨产物门禁报告并更新 `current_artifacts.quality_gate_report` |

用户只说“优化、检查、看看、给建议”一律按 `DIRECT/REVIEW_ONLY`。用户明确要求修改或保存修订版时，本技能仍先完成只读审查，然后把写入工作交给 `$resume-writer`；不得自行写文件。

## 工作流

1. **识别格式与范围**：记录文件类型、用户要求、成功读取的页面/章节和未读取内容。`.tex` 保留命令与行号；PDF 必须结合文字提取与全页渲染；DOCX 保留段落、列表和粗体位置。
2. **建立只读定位表**：每个发现绑定页码、章节、要点序号、段落或行号。样式不可确认时标 `[待确认]`，不从文本层猜视觉字重。
3. **按固定顺序审查**：先 STAR 完整性，再水项，最后加粗；完成后才检查版面密度、日期/标点、错字、链接、ATS 和敏感信息。
4. **区分事实型条目**：教育、排名、奖项、技能清单和论文书目信息不强套 STAR；科研中的个人工作内容仍检查。
5. **给唯一处置**：水项只选 `KEEP / UPGRADE / MERGE / DELETE`；加粗优先真实数字、强筛选信号和核心技术，每条目标 `1-2` 组，不整句加粗。
6. **执行范围化或完整门禁**：`DIRECT` 明确列出未检查项，不调用 Manifest 完整校验、不输出 `INTERVIEW_READY`；`ARTIFACT` 运行校验脚本并检查来源、代码、角色、STAR、抗追问、学习、跨产物和敏感信息。
7. **交付并停止**：输出按位置排序的问题、理由和唯一优先动作，明确“源文件未修改”。不生成改写稿、修订文件或新简历。

🔴 CHECKPOINT · RESUME MUTATION · STOP

用户在审查后要求写回时，展示拟修改位置和必须确认的事实，再路由到 `$resume-writer`。没有明确写入授权时停止；“优化”二字不构成授权。

## 状态边界

- 单文件/部分材料：只给 `PASS / PARTIAL / FAIL` 与严重度，不给完整流程状态。
- 完整 `ARTIFACT`：按质量门禁输出 `BLOCKED / TRAINING_REQUIRED / REVIEW_REQUIRED / INTERVIEW_READY`。
- 缺文件、Manifest 校验失败或核心角色/事实冲突时，不得用平均分或其余通过项抵消。

## 失败与恢复

| 触发条件 | 一线修复 | 仍失败则 |
|---|---|---|
| PDF 文字层缺失 | 渲染全部页面并做可见内容检查 | 标记无法提取项，不猜内容 |
| `.tex` 宏无法展开 | 检查宏定义并尝试编译/渲染 | 保留命令，样式标 `[待确认]` |
| DOCX/格式解析失败 | 使用可用的只读解析与渲染工具重试 | 只检查成功读取内容并报告缺口 |
| 某产物缺失 | 只检查已有范围并列缺口 | 最高为范围化结论，不称完整通过 |
| Manifest 或映射损坏 | 运行校验并报告具体错误 | 停止完整门禁，不猜旧文件 |
| 同一事实跨材料冲突 | 并列冲突与位置 | 标记 `BLOCKED`，不静默修正 |
| 用户要求忽略风险 | 保留 override 记录 | 不提高状态 |

## 不要做

- 不要修改、覆盖或生成源文件修订版。
- 不要交换 STAR、水项、加粗的审查顺序。
- 不要只读 PDF 文本层而跳过页面视觉检查。
- 不要给教育、奖项和论文书目机械套 STAR。
- 不要用整句加粗、平均分或漂亮版式掩盖事实问题。
- 不要把部分材料检查称为 `INTERVIEW_READY`。
- 不要自动生成简历、逐条拷打、学习路径或模拟面试。

## 完成标准

所有发现都有可复核位置；固定三阶段顺序已执行；事实型条目被正确区分；未检查范围和验证限制已说明；源文件保持不变；完整状态只在有效 Manifest 的跨产物门禁后给出。
