# Project Learning

把项目事实转换为可执行的学习顺序，而不是重新包装项目或生成简历。学习内容必须能回到代码、分析材料或用户提供的事实。

## 资源加载

1. 每次完整读取 [学习路径生成器](../../references/learning-path-generator.md)。
2. 只有用户要求“开始学习、交互学习、HTML、学习网页”时完整读取 [交互页面模板](../../references/interactive-learning-template.md)。
3. 需要摘要时读取 [输出契约](../../references/output-contracts.md) 的“学习与话术”部分。
4. `ARTIFACT` 才读取 Manifest Schema；`DIRECT/FILE_ARTIFACT` 使用用户提供或刚生成的当前学习材料。

## 交付选择

| 模式 | 触发 | 交付 |
|---|---|---|
| `DIRECT + MARKDOWN_ONLY` | 普通“学习路径/看懂项目” | 对话中的 Markdown；不创建文件 |
| `FILE_ARTIFACT` | 明确要求保存 Markdown 或生成 HTML | 版本化学习文件，直接报告路径；不创建 manifest |
| `ARTIFACT` | 已确认多阶段材料及有效 Manifest | 版本化学习文件并更新 `current_artifacts` |

显式“不要网页/只要学习路径”优先级最高，绝不生成 HTML。“开始学习/进入学习”触发交互 HTML；当前学习路径缺失但有项目材料时先在本技能内生成，连项目材料也没有时只索取一个路径或学习材料。

生成 HTML 时按当前学习路径的位置选择交付方式：路径由有效 Manifest 的 `current_artifacts.learning_path` 提供时使用 `ARTIFACT`；用户直接点名文件、粘贴内容或本轮刚生成但没有 Manifest 时使用 `FILE_ARTIFACT`。

## 工作流

1. **锁定目标与证据**：记录学习目标、项目范围、现有分析/代码、薄弱声明和时间约束。范围外关系不得读取或猜测。
2. **确定学习优先级**：使用声明风险、面试概率、掌握缺口和架构重要性排序；核心模块通常只占 `20%-30%`，不要全部标为核心。
3. **建立系统全景**：输出至少一个 Mermaid `flowchart` 架构图和一个 `sequenceDiagram` 核心链路图。实线只表示已确认关系；部分证据使用虚线“待确认”；无证据边删除。
4. **讲解模块契约**：核心/重要模块说明职责、输入、输出、上下游、关键文件、核心逻辑、设计决策、失败边界、追问和达标标准；支撑模块使用精简模板。
5. **形成练习闭环**：每个高风险或低掌握点映射到具体学习任务、参考位置和可验证标准；跨模块问题覆盖数据流、架构权衡与真实失败边界。
6. **按模式交付**：Markdown 使用当前事实；HTML 只能转换同一份当前学习路径，不重新分析或改写事实，并严格保持模板 CSS/JS 与浅色主题。
7. **验证 HTML**：检查占位符、链接、Mermaid 源码和降级文本；用 Playwright 在桌面与移动视口截图，确认无空白图、溢出、遮挡和不可读文字。验证失败则修复一次，仍失败明确记录，不宣称视觉通过。
8. **停止**：交付学习材料后停止，不生成简历、贡献映射、面试逐字稿或模拟面试报告。

🔴 CHECKPOINT · LEARNING DELIVERY

只有从对话 Markdown 切换为文件写入、生成 HTML，或需要扩大项目读取范围时展示新增产物/范围并等待确认。用户已明确要求 HTML 或保存文件时视为该产物已授权，不重复确认；这不授权修改目标项目源码。

## 失败与恢复

| 触发条件 | 一线修复 | 仍失败则 |
|---|---|---|
| 当前学习路径缺失 | 有项目材料时先生成 Markdown 路径 | 只索取一个项目路径或学习材料 |
| Mermaid 关系缺少证据 | 删除无证据边，部分证据改虚线 | 用文字链路并标 `[待确认]` |
| Mermaid 语法失败 | 修正节点 ID、标签转义和图类型 | 保留可读源码及降级说明，不输出空图 |
| HTML 运行时加载失败 | 保留 Mermaid 源码和文字链路 | 标记“图表未渲染”，不称视觉通过 |
| 浏览器验证不可用 | 做静态占位符、主题、链接和源码检查 | 明确记录未完成桌面/移动视觉验证 |
| 学习内容过多 | 只展开最高优先的 2-3 个核心模块 | 其余转为选读/速览 |
| `ARTIFACT` 映射缺失 | 报告缺失映射 | 停止，不猜最高版本 |

## 不要做

- 不要用目录结构猜测调用边、时序消息或异步关系。
- 不要用 ASCII 图替代 Mermaid，也不要只画图不写文字链路。
- 不要把所有模块标为核心或按目录顺序平铺。
- 不要重写源码片段或用通用八股替代项目证据。
- 不要在用户明确“不要网页”时生成 HTML。
- 不要修改交互模板的固定 CSS、字体、浅色主题或导航/测验脚本。
- 不要自动生成简历、话术或模拟面试材料。

## 完成标准

学习路径有证据一致的架构图与核心链路图；核心模块具备完整环节契约和达标标准；风险均映射到任务；HTML 请求有浅色页面、Mermaid 回退和桌面/移动验证；流程停在学习交付。
