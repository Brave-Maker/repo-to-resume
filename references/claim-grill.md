# Bullet Point 拷打门禁

本模块逐条验证简历声明能否经受面试追问。它不负责润色文案；发现漏洞后，把问题路由回贡献映射、经历增强或学习路径。

## 输入

- `resume.md`
- `evidence-manifest.json`
- `project-analysis.md`
- `business-chains.md`
- 可选：`enhancement-plan.md`

## 交互原则

- 一次只问一个问题；
- 等用户回答后再决定追问方向；
- 不替用户回答正在验证的事实问题；
- 用户答不上来时先给一次提示，再记录漏洞；
- 不评价用户本人，只评价声明和回答；
- 每条核心 Bullet 必须完成六层检查，不能抽样跳过。

## 六层追问

### 1. 事实确认

“你说你完成了 `{声明}`，具体发生在什么背景下？最终交付物是什么？”

验证项目是否真实存在、声明是否有明确对象和结果。

### 2. 个人角色

“这件事里哪些决策和代码由你完成？团队或 mentor 做了什么？”

验证个人归属。对于 `BORROWED_CONTEXT/NARRATIVE_FILL`，改问用户准备如何解释具体负责范围，并检查前后一致性。

### 3. 技术实现

“入口在哪里？数据经过哪些模块？关键类、函数或数据结构是什么？”

用户至少应定位到链路和 2-3 个关键代码位置。纯设计内容应给出模块接口、状态变化或伪代码。

### 4. 方案对比

“为什么用 A，不用 B？你做这个选择时最重要的约束是什么？”

至少说出一个替代方案、一个选择理由和一个代价。

### 5. 数据与验证

“你写的数字或效果从哪里来？测试环境、样本、前后值和口径是什么？”

没有数字时，验证覆盖范围、故障场景、正确性或其他可观察结果。

### 6. 边界与复盘

“依赖异常、并发放大或数据不一致时会怎样？重新做一次你会改什么？”

至少覆盖一个失败模式和一个改进方向。

## 评级规则

| 等级 | 判定 | 下一步 |
|---|---|---|
| `RED` | 核心事实、角色或实现无法解释 | 删除/降级声明，或进入增强实验室 |
| `ORANGE` | 能讲概念，不能定位代码或完成方案比较 | 复现关键链路并生成学习任务 |
| `YELLOW` | 主流程清楚，数据、边界或角色仍模糊 | 补证据、失败场景和话术 |
| `GREEN` | 业务、角色、实现、验证和取舍完整 | 进入面试话术与模拟面试 |

单条 Bullet 的最终等级取六层中最差等级，不取平均值。

## 高风险声明门禁

来源为 `BORROWED_CONTEXT`、`NARRATIVE_FILL` 或风险为 `HIGH` 时：

1. 必须完成全部六层；
2. 技术实现层必须达到 `L3`；
3. 至少回答两个失败场景；
4. 至少完成一次实现、复现、验证或完整设计任务；
5. 连续两轮无 `RED` 才能标记可面试。

用户要求直接保留时可以保留在简历草稿，但 `quality_status` 不得设为 `INTERVIEW_READY`。重测后仍为 `RED` 的核心声明使最终状态成为 `BLOCKED`；非核心声明必须移出最终简历，保留为训练候选。

## 状态流转

```text
RED -> contribution-mapper 或 experience-lab
ORANGE -> experience-lab + learning-path
YELLOW -> 补证据/边界后重测
GREEN -> interview-script-generator
```

🔴 CHECKPOINT · GRILL GATE

存在 `RED` 时暂停自动进入最终面试。若用户已授权全流程自动执行，自动生成修复任务和一轮重测；重测后核心声明仍为 `RED` 时最终状态标为 `BLOCKED`，非核心声明仍为 `RED` 时将其移出最终简历、保留训练材料，最终状态最高为 `TRAINING_REQUIRED`。

## 失败模式

| 触发条件 | 一线修复 | 仍失败则 |
|---|---|---|
| 用户不回答 | 给一个更具体的代码定位提示 | 记录 `RED: no evidence` |
| 声明没有数字 | 改验证覆盖范围或正确性 | 不强行编数字 |
| 代码不可访问 | 用架构图、伪代码和场景推演 | 最高先评 `YELLOW` |
| 回答与 manifest 冲突 | 展示冲突并要求选择 | 标记 `BLOCKED` |

## 不要做

- 不要一次抛出六个问题。
- 不要用总分掩盖事实归属的 `RED`。
- 不要替用户编完答案后判定通过。
- 不要只考八股，不验证具体项目。
- 不要发现高风险内容后静默删除。
